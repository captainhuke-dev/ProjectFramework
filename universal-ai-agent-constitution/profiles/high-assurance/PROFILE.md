# High-Assurance Profile

Status: **OPTIONAL — NON-NORMATIVE**

This profile may help a Project add assurance proportional to high consequence: source-appropriate signed or immutable identities, structured state maps, registers, receipts, schemas, CI checks, richer handoff, and durable continuation.

Activation requires an explicit `profiles` entry in `governance/UAAC-ADOPTION.yaml` under applicable Project authority. Presence does not activate this profile. It cannot create authority, redefine UAAC Core compliance, or make its mechanisms universal requirements.

The Project chooses which controls apply, their scope, their source of truth, and the evidence needed. If every mechanism in this profile is unavailable, UAAC Core remains usable through local Markdown/YAML and actual Project routes.
