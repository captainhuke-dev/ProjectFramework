# Reusable Procedures Profile

Status: **OPTIONAL — NON-NORMATIVE**

This profile may map native Skills, prompts, checklists, libraries, Human practices, or other reusable procedures to Project work under `CONST-023`.

Activation requires an explicit `profiles` entry in `governance/UAAC-ADOPTION.yaml` under applicable Project authority. Presence does not activate this profile. It cannot create authority, permission, or a dependency on a native Skill runtime.

Relevant available procedures may be considered automatically without requiring the user to name them. Their instructions remain subordinate to the task, UAAC, Project rules, and lawful Human authority.
