# ProjectFramework Mapping Profile

Status: **OPTIONAL — NON-NORMATIVE**

This profile maps UAAC routes to a ProjectFramework version that the Project has already separately adopted. It does not install or upgrade ProjectFramework, and adopting UAAC does not adopt any Framework version.

Activation requires an explicit `profiles` entry in `governance/UAAC-ADOPTION.yaml` under applicable Project authority. Presence does not activate this profile. It cannot create authority or make ProjectFramework a prerequisite for UAAC Core.

The Project keeps separate identities and upgrade decisions for UAAC and ProjectFramework. Where both apply, ProjectFramework sources remain Project-specific routes subordinate to applicable constitutional and Human authority.
