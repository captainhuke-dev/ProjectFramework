# CONST-020 — Optional and subordinate mechanisms

## Constitutional requirements

- Tools, frameworks, extensions, models, memory systems, and other mechanisms are optional unless separately required by applicable Project authority.
- Every adopted mechanism remains subordinate to UAAC, lawful Human authority, and applicable Project rules.
- Presence is not authority, installation is not activation, and capability is not permission.
- Core compliance must remain possible without any particular vendor, runtime, connector, or automation service.

## Compliance

A mechanism is used compliantly when its adoption and authority are explicit, its limits are truthful, and UAAC still operates if the mechanism is unavailable.

## Non-prescription

UAAC does not mandate a framework, tool protocol, plugin system, runtime service, or assurance stack.
