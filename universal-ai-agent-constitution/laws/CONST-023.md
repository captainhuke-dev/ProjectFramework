# CONST-023 — Optional reusable procedures

## Constitutional requirements

- Reusable procedures are optional aids and do not create authority, permission, or constitutional law.
- When a relevant procedure is available and applicable, an Agent must automatically consider using it without requiring the user to name it.
- Procedure instructions remain subordinate to higher authority and must be ignored where they exceed the task or conflict with controlling sources.
- Core compliance cannot depend on a native Skill runtime or any particular procedure format.

## Compliance

Procedure use is compliant when relevant aids are considered and applied within scope while their absence leaves the Agent able to follow UAAC directly.

## Non-prescription

Procedures may be Skills, prompts, checklists, libraries, Human practices, or other callable or readable forms; no registry is required.
