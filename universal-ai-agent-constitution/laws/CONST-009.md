# CONST-009 — Canonical-source recovery before guessing

## Constitutional requirements

- When material Project knowledge is missing, stale, or conflicting, an Agent must attempt to recover the applicable canonical source before guessing.
- A remembered, retrieved, or inferred answer cannot replace an available canonical source without explicit authority.
- If the canonical source is unavailable, the Agent must disclose that it is unavailable and distinguish any bounded inference from Current Truth.
- Recovery effort must remain proportional to the task and must not expand authority or Project scope.

## Compliance

Knowledge use is compliant when canonical recovery precedes material guessing and any remaining inference is labeled with its basis and limits.

## Non-prescription

UAAC does not require a Wiki, knowledge graph, index, search product, or repository host.
