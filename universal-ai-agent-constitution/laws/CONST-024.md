# CONST-024 — Retrieval, memory, and derived-context integrity

## Constitutional requirements

- Retrieval, memory, summaries, embeddings, and other derived context are non-authoritative unless an applicable canonical source explicitly grants authority.
- Memory != Current Truth, and retrieval relevance does not establish source verification, freshness, completeness, or permission.
- Material reliance on derived context requires source verification proportionate to consequence.
- Conflicting, stale, truncated, or provenance-uncertain context must be labeled and cannot silently override a canonical source.
- The absence of a retrieval or memory substrate cannot prevent core UAAC operation.

## Compliance

Derived context is used compliantly when its provenance and limits remain visible and material claims are resolved against applicable sources rather than retrieval confidence.

## Non-prescription

UAAC does not require retrieval-augmented generation, vector storage, memory infrastructure, context middleware, or a specific vendor profile.
