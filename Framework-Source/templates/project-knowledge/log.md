# Project Knowledge Log

Chronological append-only history for material Knowledge operations. This is not an MCP/tool transcript, raw search dump, or private chain-of-thought store.

Use exactly these heading forms:

```text
## [YYYY-MM-DD] ingest | <source title>
## [YYYY-MM-DD] query-file | <knowledge page/title>
## [YYYY-MM-DD] lint | <scope>
## [YYYY-MM-DD] maintain | <scope>
```

A transient query that neither mutates Knowledge nor files a reusable result requires no log entry.
